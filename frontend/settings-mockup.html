Import from JSON

Paste the MCP JSON configuration from the service documentation below. If the configuration uses commands like npx or uvx, make sure they are installed and available on your machine.

1

Import tips
  • Use a valid JSON object with a top-level "mcpServers" field.
  • Each server should define either "command" (stdio) or "url" (http/sse).
  • Auth: "headers" and/or "bearer_token" on URL servers.
  • Multiple servers can be imported at once.
